## 自然失败、程序保护与剩余模型缺陷

自然失败为第2、7、8轮，全部29表的前后快照均已核对。仅model_calls及reflection_settings变化；后者只有last_chat_activity_at/updated_at这两个聊天活动时间字段变化，reflection仍关闭。其他27张表的rows哈希完全相同，包含经历、事实、内部状态、事件、复习、版本、任务、关系及消息；没有把“计数相同”代替内容比较。

第2轮因保留answer额度而无法进行重评，model_call_limit降级；第8轮因experience.time_quote无当前输入依据而拒绝重评。两轮最终payload都带准确memory_failure、retain_this_turn=false和空planned变更，警告前置，正文没有“以后已记住”承诺。第7轮HTTP502没有answer或history_saved字段，不伪称存在降级回答；数据库证明未保存。

第7轮首提在episode.detail.kind输出非法preference；重提修正该字段后，又在self_updates[0].domain输出非法值。完整两次原始响应保留。对录制响应做无联网的原验证器诊断，结果存[离线错误诊断](../data/qa/current-version-acceptance-20261028/offline-error-diagnostics.json)；这是解释本次真实失败，不是新增模型实验，也没有自动修补或部分接纳提案。

全部26次实际请求的完整wire估算与调用审计一致，本地估算最大18788，未超过19200有效预算；没有超时。固定实验时钟会使多条created_at相同，因此硬错误轮按前后新增model_call ID核对请求集合，而非错误地靠时间排序配对。全部9次实际answer请求最后一条结构化上下文与API actual_context一致，完整历史消息也保存在provider原件中。

本次未发现来源权限、原文范围、事务、删除重放门禁、预算或真实机器状态方面的新程序保护阻塞；其中删除重放、私密排除、版本冲突等门禁依赖当前552项离线回归，本批自然故事未重新触发全部异常。发现的剩余功能问题为模型非法结构/枚举、单次格式不服从、不必要确认及持续偏好保存失败，不能把模型原因记作功能成功。
