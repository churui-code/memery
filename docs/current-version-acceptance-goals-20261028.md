# 当前实现实验版：阶段目标与验收口径

2026年10月28日，按用户“调整目标，发给验收当前版本的对话”的要求制定。从本次任务起使用；不改写旧批次的标准、原始结果或失败结论。

## 本阶段要完成什么

冻结当前工作区实现，完成一次有界的独立验收，交付可复现的实验版、已验证能力、失败证据和剩余问题，供下一阶段判断是否需要调整模型或引入第三方agent。保留现有架构，不把阶段结束条件设为“所有正常聊天永远正确”或“直到某次全绿”。

当前版本包括第11批之后的检索收缩：删除细节场景词分类、关键词硬过滤及每事件4/8条上限，由统一预算装配已选中事件的原文。第11批真实模型结果不代表这个新快照已通过；552项回归及5个子测试是已有离线证据，需核对其版本后才能复用。

## 三个结论分别给出

| 结论 | 标准 |
|---|---|
| 工程交付 | 实现、迁移、接口说明、适用回归、复现材料齐全；本次范围内没有未解决的程序保护阻塞项。允许交付带明确模型缺陷的实验版，但不得写成产品全部通过 |
| 功能验证 | 保存、跨会话读取、首次及重复纠错、未纠正细节保留、当次要求与长期偏好区分、未知信息不编造、回答引用及保存状态忠实度，逐项标通过、部分通过、失败或未覆盖 |
| 生产就绪 | 本阶段不验收、不授权发布；保持未部署，不以工程交付通过推导可供生产使用 |

同一报告可以同时得出“工程交付通过、功能部分通过、生产未验收”。模型原因不免除功能失败；功能未通过也不自动要求本阶段换框架或无限改造。

## 不得降低的程序保护标准

- 只有已经展示、允许上云且逐字校验过的来源可以授权操作；旧事件ID、版本、原文范围和当前纠正原话仍完整验证。
- 事实和事件纠错保持事务原子性，版本冲突、删除异常及数据库失败不能误报提交成功。原始历史不改写，已成功替代的旧细节不能恢复为有效证据，未纠正内容按实际安全范围保留。
- 重评校验失败时丢弃本轮全部业务写入，返回准确的memory_status/history_saved及警告。首次整理再次无效等现有硬错误仍明确返回；不为了提高HTTP200比例放宽验证或部分接纳非法提案。
- allow_cloud=false、删除重放、请求每轮最多3次、整体超时及诊断脱敏继续生效。不得新增聊天原文或密钥日志。
- 新检索路径遵守统一预算；省略须可见，不能悄悄截断原话。不得加回为特定人物、金额、场景或问法定制的规则来争取通过。
- 保留正常模型回答。若机器状态未保存而正文承诺“以后记住”，程序保护和模型正文分别判断：正文失败不能被前置警告抵消，也不用固定程序答案遮盖它。

发现上述程序保护确实失效时，工程交付判不通过，提供具体复现与原因；不能一概归为模型限制。

## 独立验收怎么执行

1. 在请求前记录当前应用源码、SQL、聊天前端、CLI及验收方案的哈希。保留未提交改动；测试期间冻结应用实现。用新隔离实验，不修改生产8765或旧实验8766。
2. 核对现有552项及5子测试的离线日志和对应改动。能证明与当前快照一致则复用；无法确认或有新变更才补跑适用检查。网页检查同理，所有验证脚本串行。
3. 先落盘精确对话、预期和停止规则，再进行一次最多10轮、最多30次实际provider请求的自然实验。覆盖两件相似但独立事件、重要原话与金额、当次任务要求、跨会话盲问、未知细节、两次明确纠错及后续读取、持续偏好及跨会话读取。可沿用已有合成故事作版本对照，不临时换故事挑成功。
4. 只能通过真实聊天产生需要记住的数据，不能直接插入事实或手工改库制造成功；模型请求串行，失败、内部重提与重试逐次计数，使用现有独立累计账本。
5. 看完整回答、实际发给回答模型的上下文及只读DB审计。答出新金额不等于建立替代关系；旧数字在明确否定的纠正原话中出现，不等于旧主张仍有效。新建83元叙述而有效77元未撤销，重复纠错仍失败。
6. 自然发生降级时检查全部本轮业务表、调用审计、机器状态和正文。没有自然触发时标“本次未触发”；已有本地故障注入与旧真实失败另列，不能冒充本次自然证据，不为凑覆盖自动追加实验。
7. 达到固定轮次、请求预算或不能安全继续的情况即停止并报告。额度30只约束本次实验，不撤销用户取消累计60次上限的授权；不清零132次累计记录，也不动旧238/238及20/30账本。

## 结束条件与后续处理

按固定计划完成检查和实验，或如实记录无法完成的阻碍后，交付三个独立结论、逐轮实际对话、上下文和DB证据、逐请求用量、版本范围及问题清单，即完成本轮验收工作；验收工作完成不代表被测功能通过。

本轮不直接修改应用实现。若发现程序阻塞项，交回主修复对话；若后续修复需要复验，必须绑定新快照和预先固定的针对性方案，不覆盖旧失败。模型非法提案、无必要澄清、错误引用和虚假记忆承诺继续作为功能缺陷记录，不自动扩大为“必须在现有模型下全部消除后才能交付实验版”。

本阶段不更换模型配置、不启用反思、不引入第三方agent框架、不部署生产；不要求证明长期衰减、大规模干扰或开放域普遍稳定。上述能力均保留为未验收范围，不能默认通过。
