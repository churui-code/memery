# v0.5 记忆巩固与周期反思

反思在两次对话之间读取已有外部证据，形成可修正的内部解释。它不训练模型、不修改程序，不创造新的生活经历，也不主动发消息或执行目标。

## 运行结构

现有 API 与本地索引 worker 继续运行；新增独立 `reflector` 进程，单次执行一轮，模型等待不占用索引 worker。生产与实验复用 `ReflectionService`、同一提案校验器和同一事务存储入口。实验不会注册到生产调度器。

流程为：本地资格检查 → 选择原文证据 → 生成最多八项内部更新 → 第二次请求复核原提案 → 原子提交。空提案只需一次请求。复核只接受或拒绝，不能加提案、换目标或扩大检索。

`reflection-v1.5` 由服务端将提案正文和理由拆成完整句子，复核必须逐句给出来源对应和支持判定，不能自行省略某个分句。任一句缺少依据或存在冲突，整轮不写入，也不消费待处理材料。情绪修订显式声明升高、保持或降低，并与本轮冻结的当前衰减强度作数值校验。语义复核仍依赖模型判断，真实验收必须检查最终写入内容，不能把协议校验通过当成内容正确。

运行记录保留来源清单、原文范围、版本与哈希、目标版本、策略版本、输入签名、租约、状态、调用次数和提供商用量。生产不存提示正文、思维链或失败提案正文。运行开始时重建冻结来源，不把运行表当作另一份原文档案。

## 来源与内部状态

原始档案仍是唯一的经历证据。事件提示、梗概、既有认识都属于派生表示；旧认识可辅助解释，但不能独立证明新增事实。每条反思更新必须引用实际提供、角色与范围已核验的原文证据，至少一条来自本轮新增材料。

自我状态延用既有版本历史，增加生成来源 `conversation`／`reflection`、反思运行 ID 和证据定位。支持情绪、关系、身份、观点、目标五类变化。新情绪评价保存理由及新版本，不自动把衰减后的旧情绪恢复到当年强度。

所有实际曝光来源都进入提交校验和来源依赖，包括背景中显示的旧事件、自我状态以及目标键的元信息。失效但未删除的认识可以仅提供目标 ID、键和版本，以新原文修订；不会把失效正文重新作为依据。目标元信息递归检查原始来源的云权限，撤云或删除后连目标名称也不发送。普通联想边仍只用于检索，删除和撤云沿来源依赖传播。原文、用户事实、事件重要性、有效重提次数不受反思修改。

## 调度与配额

| 默认值 | 行为 |
|---|---|
| 自动开关 | 新安装关闭；验收后可通过鉴权 API 开启 |
| 本地资格检查 | 每 15 分钟，无模型请求 |
| 日常到期 | 上海时区每日 03:00；重要性 ≥0.8 或已验证纠错可提前 |
| 自动空闲要求 | 最近 15 分钟没有聊天，距上一轮启动至少 6 小时 |
| 生产每日上限 | 上海真实自然日最多两轮、四次模型请求，失败占用额度 |
| 单轮期限 | 240 秒；最多两次请求，不自动重试；租约 300 秒 |
| 原文选择 | 最多 12 个待处理事件，含相关旧事件总计最多 24 个 |
| 输入预算 | 默认 24,000 估算 token，预留 20%，工具与完整请求均计入 |

手动排队可在自动关闭时执行，不受空闲与六小时间隔限制，仍遵守证据去重和每日配额。无新增证据不调用模型。错过多个周期不会逐天补跑。失败材料保持未处理，未来满足资格时可以重新尝试。

事件活跃度、情绪及调度资格使用业务时钟；生产业务时钟等于真实时间，实验可单向推进。配额、租约、网络期限始终使用真实时钟。实验另外设置整次运行共享的云调用上限，复制快照或推进多年不会重置计数。模拟反思记录逻辑阶段，不伪造云调用或占用真实调用额度。

## 一致性与删除

反思提交不调用聊天归档。事务检查全局变更状态、任务租约、所有来源的权限及版本、目标状态的预期版本；任何检查失败均不写入部分状态。成功更新、来源依赖、处理游标和运行完成状态一起提交。

新增或纠正的外部证据才产生待处理材料。反思输出不能触发自身；同一材料与策略成功处理后不重复建立版本。被明确删除的最新状态键阻止后台重建，只有后续成功对话根据新材料创建新版本才能重新开放。

删除、撤云、纠正取消相关排队或运行任务。迟到模型响应和失效租约无法提交。恢复备份时先迁移、重放独立删除账本并清理旧租约，再启动调度。保留既有保守派生档案删除语义。

## 验收范围

固定 12 组成对合成场景测试跨事件理解、纠错、关系、情绪、目标及重复整理边界。真实模型每组最多八次调用，总上限 96；比较关闭／开启后的实际回答上下文。报告区分改善、无变化和退化，不把认识数量增加直接当成质量改善。所有失败结果保留；确定性、来源错误、无依据写入、权限泄漏失败阻止上线。

## 真实验收后的保守校验

在模型复核之外，服务端对可识别的范围扩大进行拒绝：新增排他或必要前提、与同一谓词相关的频率限定丢失、来自未绑定来源的独占日期/金额或显著原文片段。正文与形成理由都检查，事务内从冻结原文重建并复验。该校验是有限的文本约束，不是完整自然语言逻辑证明，可能保守拒绝合法改写；无法据此宣称语义错误已被消除。

反思工具的证据及单元 ID 使用本轮动态枚举，模型输入显式列出各提案的来源集合。非留存聊天协议仍禁止经历与自我更新；明确只读的分支由服务端直接落实，其他分支的协议违约仍拒绝整轮。

反思模型现在不接收事件标题、梗概、重要性理由、情绪理由或派生细节解释。它们仅在本地选择相关事件；模型接收核验过的完整原文、必要来源标记以及明确作为背景的既有自我状态，避免将索引元数据改写成新的目标依据。事件读取接口仍提供原有表示。

对话首次判断若明确 `retain_turn=false` 且 `actions` 为严格空列表，服务端先清空模型夹带的经历、事件、状态和重提，再进行严格校验并回答。校验后清除本分支的 `clarification`：没有待执行记忆操作时，回答根据实际原文处理歧义，不接收判断阶段未经验证的转述提示。检索仍可执行，未知字段及错误格式仍拒绝；非空事实或遗忘操作不进入此分支，原有持久化校验不放宽。未展示旧认识不构成此前从未有过认识的证据。
